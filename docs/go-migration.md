# Миграция на Go — проверка 22 октября 2026

Исходная Python-версия: `54c7f511de1d898b902aa4f5c5003ffdfd8bd417`.
Бот полностью перенесён в `cmd/fsbot` и `internal/fsbot`. Python нужен только для
необязательного восстановления эталонных тестовых данных из старого коммита.

## Образ и слои

Сравнение локальных production-сборок **linux/arm64**, `docker image inspect .Size`:

| Реализация | Размер |
|---|---:|
| Python, исходный Dockerfile | 141 513 010 байт |
| Go, scratch | 17 115 131 байт |

Уменьшение на 87,9%. Размер сжатых OCI-слоёв: 5 086 502 байта для arm64 и
5 427 745 байт для amd64. Это разные метрики: размер на диске и передача слоёв.

SDK и зависимости загружаются до исходников. Инструменты тестирования
устанавливаются до копирования кода. Повторная сборка после правок использовала
кеш обоих слоёв. Компиляция использует кеш BuildKit. Сертификаты CA и каталог
данных копируются раньше бинарника; изменяемый бинарник находится в последнем
слое. В архиве финального образа проверено отсутствие исходников, тестов,
Python, zbar, shell и пакетного менеджера. Часовые пояса встроены в бинарник.

Сборки amd64 и arm64 проверены с экспортом в локальный OCI-архив. Сборщик
работает на своей архитектуре, Go компилирует для целевой; QEMU не нужен.

## Проверки

- Все 194 исходных Python-теста прошли в Docker без сети.
- Все 1 415 замороженных сравнений Python/Go прошли.
- Go-тесты, включая `-race`, прошли локально и в Linux-контейнере без внешней сети.
- Проверены OAuth-подписи и HTTP-контракты через локальные сервисы.
- Проверены текст, фото, авторизация, правки, двойное подтверждение, создание
  продукта, защита неизвестных результатов, частичная запись и пошаговый `/undo`.
- Проверены конкурентные захваты черновиков и отмены через разные подключения.
- Go открыл синтетическую базу, созданную реальным Python-хранилищем, сохранил
  привязку, часовой пояс, barcode binding, старые статусы и ID для `/undo`.
- Production-образ открыл ту же базу из отдельного тома с владельцем root,
  исправил владельца и работал под uid/gid 10001. Повторный запуск с явно заданным
  пользователем 10001 также прошёл.
- Проверены свежий и отсутствующий heartbeat, конфликт polling и остановка.
- `go vet`, форматирование, `actionlint`, `git diff --check` прошли.
- `govulncheck` не обнаружил известных уязвимостей в проверенном коде.

Реальные аккаунты Telegram/FatSecret, публикация в реестр и production-развёртывание
в эту проверку не входили. GitHub Actions обновлён, но удалённый CI ещё не запускался.
